# 🔬 中国半导体技术突破监控台 (China Semiconductor Breakthrough Tracker)

每日自动抓取**国内半导体产业链的技术突破类新闻**，按领域归类、去重、累积，生成可筛选的情报看板。
聚焦**企业级技术进展**（创业公司 + 成熟企业），过滤股价行情、财报融资等非技术噪音。

## 在线看板（GitHub Pages，云端自动更新）

**https://fenggg1988.github.io/china-semi-tracker/**

由 GitHub Actions 每天在云端自动抓取并提交，Pages 随之重建，**不需要本地电脑开机**。

## 监控领域（8 类）

| 领域 | 覆盖重点 |
|------|----------|
| 🔴 光刻机整机 | 上海微电子(SMEE)、宇量昇、EUV/DUV、浸没式、套刻精度 |
| 🔴 光刻机电源/光源 | 科益虹源、炬光科技、准分子激光、ArF/KrF 光源、EUV 光源 |
| 🟠 机台/工件台 | 华卓精科、双工件台、精密运动台、纳米级平台 |
| 🔵 镜头/光学系统 | 国望光学、长春光机所、茂莱光学、光刻物镜、精密光学元件 |
| 🟣 光刻胶与电子材料 | 南大光电、彤程新材、晶瑞、徐州博康、电子特气、CMP 材料 |
| 🟢 存储芯片先进制程 | 长江存储、长鑫存储、3D NAND、DRAM、HBM、堆叠层数 |
| 🔵 逻辑芯片先进制程 | 中芯国际、华虹、GAA/FinFET、麒麟/昇腾、先进节点代工 |
| 🟢 光通讯/光模块 | 中际旭创、新易盛、源杰、硅光、800G/1.6T、CPO |

> **关于「机台 / 镜头」**：这两个环节属极细分领域，公开报道数量本身很少，
> 每日新增往往为 0～2 条，属正常现象（非抓取故障）。

## 运行

```bash
pip install -r requirements.txt
python scrape_news.py
```

输出：

- `data/news.json` — 累积历史（按标题指纹去重，保留 120 天）
- `data/news.csv` — 长表导出，便于 Excel / 二次分析（UTF-8-BOM）
- `index.html` — 自包含看板（内嵌数据 + 原生 JS 筛选，双击即可打开）
- `scrape.log` — 运行日志

Windows 本地双击 `run_scraper.bat` 亦可。

## 自动化

GitHub Actions 每日 UTC 01:10（北京时间 09:10）云端运行：

`.github/workflows/daily.yml`

也可在仓库 Actions 页面手动 `Run workflow` 触发。

## 看板功能

- **领域筛选** —— 8 个领域胶囊标签，带实时计数
- **企业筛选** —— 自动识别标题中的重点企业（拓荆、中际旭创、长江存储…），点击过滤
- **仅看技术突破** —— 按标题信号词（量产/交付/攻克/流片/验证…）打分，过滤纯行情类
- **仅看今日新增** —— 只看本次抓取新入库的条目
- **关键词搜索** —— 标题 + 来源全文检索

## 分类与评分逻辑

1. 标题命中领域关键词 → 归入得分最高的领域（子领域优先于「光刻机」宽泛词）
2. 噪音过滤：股票行情（涨跌幅/成交额/融资融券）、公司公告（减持/回购/担保/股东大会）直接丢弃
3. 突破评分：`+2` × 正向信号词（量产/下线/攻克/验证/流片…），`-3` × 负向词（股价/财报/减持…）
4. 去重：标题归一化（去标点、字母转小写）后取 SHA1 指纹
